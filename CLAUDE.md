# Notes for Claude

## Branches

- Always work on a branch with a short, descriptive name in kebab-case that says what the change does, for example `keep-manual-light-on` or `multiple-blocking-entities`.
- Never use the auto-generated session branch names (like `claude/adoring-babbage-hcv1fr`). If the session hands you one, create a properly named branch from the latest `main` and push that instead.
